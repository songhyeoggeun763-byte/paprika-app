# 파프리카 방제수첩

파프리카(단고추류) 병해충 방제 약제 추천, 작용기작 중복 확인, 혼용 가능 여부 확인, 방제 기록을 하는 웹앱입니다.

앱 주소: https://songhyeoggeun763-byte.github.io/paprika-app/

## 오프라인 사용
- 인터넷이 될 때 한 번 열면, 그다음부터는 인터넷 없이 열립니다.
- 폰: 브라우저 메뉴의 "홈 화면에 추가" 또는 "앱 설치"로 설치합니다.
- PC(Chrome, Edge): 주소창의 설치 단추로 설치합니다.

## 자료 저장
- 입력한 자료는 이 기기의 브라우저에만 저장됩니다. 서버로 보내지 않고, 다른 기기와 공유되지 않습니다.
- 브라우저 자료를 지우면 함께 지워집니다. 설정 화면의 "전체 백업 내려받기"로 자주 백업하세요.

## 자료 기준
- 농약 등록 정보: 농약안전정보시스템(PSIS) 농약 검색 2026-11-04 조회본. 실시간 연동이 아니므로 사용 전 제품 라벨과 PSIS에서 확인하세요.
- 작용기작: 농약 표시기준 별표 8, FRAC Code List 2026, IRAC MoA Classification 11.5.
- 혼용: 제조사 공개 혼용 자료 일부. 통합 공식표가 아니며, 자료에 없는 조합은 "확인 필요"로 표시합니다.
